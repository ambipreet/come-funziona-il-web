Simulatore 2: Costruttore di richieste HTTP

Scegli un Metodo HTTP e una Risorsa sul server, poi invia la richiesta per osservare il messaggio HTTP e il codice di stato restituito.

Client (La tua richiesta)



GET /index.html HTTP/1.1 Host: www.esempio.it User-Agent: BrowserStudente/1.0

Server (La risposta)

200 OK

Spiegazione: Il server ha trovato /index.html e ha inviato il codice della pagina al browser.

HTTP/1.1 200 OK Content-Type: text/html; charset=UTF-8 Benvenuto nella Home!
